# 踩坑清单

动手前先过一遍。这些坑的共同点是**不报错**，只是结果悄悄不对。

## 精度

1. **8-bit 坐标不够用**。u 一个台阶 = 1/255 ≈ 0.0039；某块屏横向只覆盖 Δu≈0.6，
   折算到成片就是每个台阶宽约 40 像素的糊块。实测平均误差 18–27/255，
   而 16-bit 是 0.9/255。换任何算法都救不回来，只能提精度。
2. **PIL 和浏览器读 16-bit 多通道 PNG 都会静默掉成 8-bit**。
   所以：精度只能靠高低位打包；**验收脚本里也不要用 PIL 读 16-bit 当基准**
   （否则你会以为"16-bit 也没用"，其实一直在用 8-bit 数据）。
   单通道 16-bit PNG/TIFF 才会给到 `uint16`。
3. **16-bit 不能交给硬件插值**。高低位分开存时，GPU 的亚像素精度误差会被放大 256 倍
   （它只按字节插，进位的地方就崩）。必须 `texelFetch` 取 4 格、拼回 16-bit 再插值。

## 预乘

4. **渲染器输出的"数据通道"常常已被 alpha 预乘**（`u_baked = u_true × 覆盖率`）。
   判断方法：看 `alpha=0` 的地方 R/G 还是不是正常坐标值。
   * 是（未预乘）→ 普通平均降采样即可；
   * 不是（预乘了）→ 必须按 `Σu_baked / Σ覆盖率` 反算，否则屏体边缘一圈脏。

   **同一个项目里两条链可能相反**，别照抄另一版的处理方式。

## 浏览器

5. **不要用带 alpha 的 RGBA 存数据**：浏览器上传贴图时会把 RGB 按 alpha 预乘掉，
   数据直接毁。拆成两张 RGB（gridU / gridV），遮罩单独一张。
6. **`1.0 - uv.y` 不能漏**：DCC 的 v 原点通常在左下，贴图的 `v=0` 是图像第一行。
   漏了就是整张图上下颠倒——而这个错误在验收里会被一眼看出来，别绕过验收。
7. **文件选择框必须是真的挂在 DOM 上的 `<input type=file>`**：临时 `new` 一个再
   `click()`，新版 Chrome/Edge 和部分内嵌预览窗口会直接忽略，表现就是"点了没反应"。
8. **应用内预览窗口会禁用系统文件框**：说明里要写清"用系统 Edge/Chrome 打开，
   或改用拖拽 / Ctrl+V 粘贴"。
9. **加个"全黑"自检**：素材尺寸超出显卡贴图上限时会静默出一张全黑图。
   生成后抽查缩略图，全黑就明确提示，别让用户以为切错了。

## Nuke

10. **`-t` 打不开带中文路径的 `.py`**（`UnicodeDecodeError`）→ 先把脚本拷到纯英文目录再跑；
    读中文路径的**数据文件**没问题。
11. **Write 会吃掉路径里的反斜杠**（`D:\a\b.png` → `D:ab.png`）→ 脚本里一律正斜杠。
12. **`-t` 不会把额外命令行参数交给 `sys.argv`** → 用环境变量收参数。
13. **`STMap` 的 input 0 是 src、input 1 才是 map**；`uv` 通道默认 `none`，
    这时它不报错、原样吐回输入，极易误判。
14. **`nuke.nodes.Multiply()` 不是 Merge 版的乘法**，第二路输入会被无声忽略。
15. **遮罩要写成 RGB**：单通道灰度图进 Merge 相乘时，绿蓝会乘 0，画面直接废。
16. **Write 的 `datatype` 取值因格式而异**（如 tiff 是 `'32 bit float'`，不是 `'32 bit'`）；
    有些版本没有 `rawWriter`，别指望写 `.raw`。
17. 重启 Nuke 前处理掉 `*.nk.autosave`，否则"是否恢复自动保存"对话框会阻塞自动化；
    弹出来时用关闭窗口解决，**绝不要点 Yes**。
18. **别用 DCC 自带的窗口截图接口去拍一个正在干活的 Nuke**。实测用
    `dcc_diagnostics__screenshot`（Windows.Graphics.Capture）抓某个 Nuke 窗口时，
    调用会卡死，**最终把那个 Nuke 进程带崩**（工程文件没丢，但内存里未保存的改动会没）。
    要拍图走两条安全路子：① 让被拍进程自己用 Qt 渲染（`QWidget.grab()`，但
    OpenGL 面板会是黑的，只适合拍对话框/面板）；② 直接用系统的截图工具人肉截。
19. **PowerShell 5.1 把无 BOM 的 UTF-8 `.ps1` 当 GBK 读**，脚本里的中文常量会变乱码，
    严重时直接把语法搞崩。本技能的 `.ps1` 一律只写 ASCII；你自己加脚本时也一样。

## 工程习惯

18. **只读副本**：接管别人的管线时，烤图一律用副本，Write 全部改到本地 scratch，
    原工程与素材一个字节都不动。
19. **每一步留一个能独立跑的脚本**（导出 / 打包 / 出页面 / 验收 / 现渲对照），
    而不是一个大脚本；出问题能立刻定位到哪一步。
20. **验证脚本和实现脚本一起交付**：半年后换机位重烤时，验收脚本就是安全网。
